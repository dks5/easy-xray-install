Установка и настройка XRay Core

Интерактивная инструкция настройки и проверки VPS

⚙️ Исходные параметры сервера

? Введите IP и порты вашего сервера. Все команды в инструкции ниже автоматически обновятся под ваши значения.

Заполните данные вашего VPS — они автоматически подставятся во все команды для копирования:

1 Заказ VPS-сервера

Закажите сервер у провайдера (например, ISHosting). Подходит тариф «Лайт» с локацией как можно ближе к вам (например, Финляндия), система Ubuntu 22.04 / 24.04 x64. После оплаты впишите полученный IP в форму выше.

2 Предварительная диагностика доступности и вход

? Одиночный timed out на 22 порту не означает блокировку ТСПУ: если сервер уже переведен на нестандартный порт, фаервол может молча отбрасывать (DROP) пакеты на 22 порт. Оценивайте оба порта в паре.

👁️ Ожидаемый результат:

3 Смена пароля

Сгенерируйте надежный пароль:

openssl rand -base64 32
👁️ Ожидаемый результат:
K9f+m3QxL7P9v... (скопируйте выведенную строку для следующей команды)

Задайте его для текущего пользователя:

passwd
👁️ Ожидаемый результат:
New password:
Retype new password:
passwd: password updated successfully

5 Установка скрипта XRay с репозитория

Вариант 1 — Классический транспорт TCP + XTLS-Vision (VLESS + Reality + TCP):

wget -qO- https://raw.githubusercontent.com/ServerTechnologies/simple-xray-core/refs/heads/main/xray-install | bash

Вариант 2 — Транспорт XHTTP / SplitHTTP (VLESS + Reality + XHTTP):

wget -qO- https://raw.githubusercontent.com/ServerTechnologies/simple-xray-core/refs/heads/main/xhttp-xray-install | bash
👁️ Ожидаемый результат в конце установки:
Xray service started / Active: active (running)

6 Проверка открытых портов на сервере

Убедитесь на самом сервере, что SSH и XRay (порт 443) активны и слушают нужные порты:

👁️ Ожидаемый результат:
tcp  LISTEN 0  128  0.0.0.0:55969  0.0.0.0:*  users:(("sshd",...))
tcp  LISTEN 0  511  0.0.0.0:443    0.0.0.0:*  users:(("xray",...))
